# Zotero Vocab Book Pro

在 Zotero 阅读论文时收录生词、保存原句与页码，并使用熟练度分级和闪卡复习。

## 安装

从本仓库 Releases 下载 `zotero-vocab-book.xpi`。在 Zotero 的“工具 → 插件”中，点击齿轮，选择“从文件安装插件”。更新后建议重启 Zotero，以刷新语言资源。

当前已在 Windows 的 Zotero 10.0.6 上调试；清单声明支持 Zotero 7–10，其他版本尚未逐一实测。

## 使用

- 在 PDF 中划选单词或短语，点击“加入生词本”。
- 划选句子后点选多个词，分别收录，保留同一原句、译文和 PDF 页码。连字符词和缩写不会拆散；失败的词保留选中，可重试。
- 生词本默认显示当前论文；可切换全部生词，同一个词会保留不同论文的来源。
- 在右侧生词本中搜索、切换熟练度和排序；点击“修改释义”纠正翻译，人工修改会保留。
- 点击“定位原词”回到 PDF 原选区并临时高亮。新收录词记录字符位置；旧数据按页码和例句尝试查找，缺少文字层或原位置信息时会回退选区/页码。
- 点击文献列表上方工具栏的书本图标“阅读管理”，加载当前分类/搜索列表，标记已读、保存阅读笔记、展开每篇的生词预览。切换列表后点击“刷新当前列表”。
- 阅读笔记编辑后点击“保存笔记”；未保存草稿在当前窗口内刷新/收起时保留，关闭窗口前请保存。
- 点击“闪卡背词”回忆释义，翻面后评分；点击定位按钮返回原文。
- “导出 Anki”按当前文献/全部生词范围，将两列 TSV 复制到剪贴板。导入 Anki 时允许 HTML。

## 翻译与数据

在 Zotero“设置 → 生词本”填写百度 APP ID 和密钥，点击“保存并测试连接”。侧栏齿轮也可打开设置。旧版 `APPID#密钥` 会自动沿用；可在此关闭划词弹窗、自动翻译或词典查询。关闭自动翻译后，选择文字和批量加词不会请求翻译；“翻译选区”和侧栏“查词入库”仍可手动查询。长选区会显示滚动条，超过翻译接口长度时会明确提示仅翻译开头部分。词典释义与发音使用有道服务。查询内容会发送给对应服务；生词列表和翻译密钥保存在本机 Zotero 配置中，不上传至本仓库。公开源码和安装包不含预设密钥。

保留原插件 ID `vocab-book@custom.zotero.org` 及 `extensions.vocabbook.*` 配置键，升级不会主动清空已有生词。

## 开发与发布

```sh
npm ci
npm test
python build-xpi.py
```

Windows 也可以运行 `./build-xpi.ps1`。构建只打包明确列出的运行文件，不包含测试、调试记录和本机数据。

GitHub Actions 在 main 分支推送时运行测试并构建 XPI；版本尚未发布时自动创建对应 tag 和 Release，上传 XPI 与 update.json。已发布的版本不被覆盖。也可手动运行工作流。发布新版本前同步修改 manifest.json、package.json 和 package-lock.json 的版本。

阅读状态和笔记保存在本机 `extensions.vocabbook.readingProgress`，按文库与文献键隔离；它们不写入文献原字段，也不通过 Zotero 库同步。

社区市场收录步骤和可提交内容见 [收录说明](docs/marketplace-submission.md)。

本地旧版使用的更新地址为占位地址，需要手动安装一次本仓库的版本，之后才会使用新的更新地址。
