# 多功能单词本 · 使用教程

[返回项目首页](../README.md) · [下载最新版本](https://github.com/RedkieZhang717/vocabu_text/releases/latest) · [反馈问题](https://github.com/RedkieZhang717/vocabu_text/issues)

本教程适用于 v2.6.0。插件原名 Zotero Vocab Book Pro。

## 1. 安装后在哪里打开

在 Zotero 的“工具 → 插件”中安装 `zotero-vocab-book.xpi`。如果升级后仍显示旧名称，请重启 Zotero。

| 入口 | 适合做什么 |
| --- | --- |
| PDF 中选择文字后的浮窗 | 小翻译图标查询；下拉面板中收词、批量选词或合并词组 |
| 右侧栏“多功能单词本” | 查看生词、修改释义、搜索、闪卡复习、Anki 导出 |
| 文献列表上方工具栏的书本图标 | 打开阅读管理，查看文献卡片、标记状态、记录笔记 |
| Zotero“设置 → 多功能单词本” | 百度凭据、自动翻译、划词弹窗和词典开关 |

PDF 需要有可选择的文字。扫描图片型 PDF 没有文字层时，无法直接划词。

## 2. 配置翻译，或只使用收词功能

### 需要百度翻译

1. 打开 [百度翻译开放平台](https://fanyi-api.baidu.com/)，按照平台指引开通通用翻译服务，并获取自己的 APP ID 和密钥。接口说明见 [官方文档](https://fanyi-api.baidu.com/doc/21)。
2. 打开 Zotero“设置 → 多功能单词本”。
3. 将 **APP ID** 和 **密钥** 分别填入对应输入框，不要将整段 `APPID#密钥` 填入单个字段。
4. 点击“保存并测试连接”。出现“连接成功”表示当前配置可用；失败时按页面提示检查凭据、服务权限与网络。
5. 按需要启用“选中文字后自动翻译”和“使用有道词典补充音标和释义”。

旧版本保存的百度配置会自动沿用。修改输入框后需点击保存；两个字段同时留空再保存会清除百度配置。百度的额度与计费以平台当前规则为准。

### 不在划选时自动翻译

1. 保持“启用 PDF 划词弹窗”开启。
2. 关闭“选中文字后自动翻译”。
3. 此时选择文字只显示紧凑的小图标。点击翻译图标才显示译文；展开下拉面板并收录时，会主动获取所选词／词组的释义。

无需百度密钥也可以收录，启用词典时会尝试通过有道补充词义。若服务不可用，词条会明确显示“待补充释义”，随后可点击“补查释义”或手动修改。手填词组释义后收录可跳过该词组查询。翻译图标、收录、补查、右侧栏“查词入库”及发音均属于主动查询。

## 3. 收录单词、短语和一整句中的多个词

### 单个词或短语

1. 在 Zotero 内置阅读器打开 PDF。
2. 用鼠标划选需要记住的单词或短语。
3. 点击小翻译图标旁的下拉入口展开面板。“单词”模式中单个词会默认选中。
4. 点击加入按钮收录。要整体保存短语，可切换“词组”模式，检查或编辑词组文本后点击“收录词组”。

插件会记录来源文献和可用的页码／选区位置。开启自动翻译时会提前查询；关闭时在点击收录后查询，避免空释义。查询失败仍可保留词条，并明确提示待补充。

### 批量收录

例如，划选包含 `uncertainty`、`evidence`、`reliable` 的句子时，不必来回选择三次：

1. 先划选整句或一段文字。
2. 展开下拉面板，选择“单词”模式，在可滚动的候选词区域点选生词。候选词会去重，保留连字符词和缩写。
3. 确认选中数量，执行批量加入。
4. 成功保存的词会取消选中；收录失败的词继续保留选中，便于重试；仅查询失败的词会保存为待补充释义。

每个词分别入库，共享这次选择的原句及可用译文。候选词和浮窗支持滚动；特别长的选区会提示仅翻译开头部分，完整选区仍可用于收词。

### 连续词组与手动词组

例如从一句话里提取 `in terms of`：

1. 展开下拉面板，切换“词组”。
2. 先点 `in`，再点 `of`，中间的 `terms` 会一起合并；重复出现的词按在原句中的位置区分。
3. 检查输入框中的词组，可直接编辑文字。也可以跳过点选，手动输入词组。
4. 可选填写自己的释义；留空时，点击“收录词组”主动查询释义。整个词组作为一个条目保存，并保留原句和位置。

再次点击下拉入口可收起面板；在展开面板中按 Escape 也可收起。发音入口位于短选区的下拉面板内。

## 4. 查看生词、纠正释义和回到原文

打开右侧栏“多功能单词本”。首次进入默认是 **当前文献**；点击范围按钮可切换 **全部生词**。

- **搜索：**输入单词、释义或例句中的内容。
- **筛选与排序：**使用熟练度按钮切换等级，按最新、生疏优先或字母排序。
- **补查：**旧空释义和查询失败词条显示“待补充释义”，点击“补查释义”重新获取。已有人工释义会保留。
- **纠错：**点击卡片上的“修改释义”，编辑后保存；取消则保留原来的内容。后续再次查询该词时，不会覆盖人工修改。
- **定位：**点击“定位原词”或页码定位按钮，打开对应 PDF 并尝试定位、高亮。

同一个词在不同文献出现时，单词条目共用词义和熟练度，同时保留多个来源。切换到某篇文献后，会优先使用这篇文献的来源定位。

新收录词会尽量保存精确位置。旧数据、扫描 PDF 或缺失原位置信息的词，可能只能定位到原选区或页码；没有关联 PDF 的词无法定位原文。删除或更换附件后，也可能需要重新收录以更新来源。

## 5. 闪卡复习与 Anki 导出

### 闪卡背词

1. 先选好范围：当前文献或全部生词。
2. 点击“闪卡背词”，根据单词和例句回忆释义。
3. 点击显示释义的按钮翻面。
4. 按“生疏／模糊／掌握”评分，进入下一张；可通过等级筛选集中复习生疏词。
5. 点击“退出闪卡”返回列表。

当前提供熟练度分级与闪卡复习，没有按日期安排的间隔重复计划。

### 导出到 Anki

1. 选择“当前文献”或“全部生词”的导出范围。
2. 点击“导出 Anki”，等待“已复制 Anki 格式”。导出按文献范围进行，不按当前搜索结果或熟练度筛选缩减。
3. 将剪贴板内容粘贴到文本文件，保存为 UTF-8 的 `.tsv` 文件。
4. 在 Anki 中导入，按制表符分隔两列：第一列为正面，第二列为背面，并允许字段包含 HTML。导入选项可参考 [Anki 官方文本导入说明](https://docs.ankiweb.net/manual/importing/text-files)。

背面包含释义、可用例句／译文和来源。此操作是导出，不会建立与 Anki 的持续同步，也不会删除 Zotero 中的生词。

## 6. 使用阅读管理卡片

在 Zotero 主窗口，先选择分类或设置搜索条件，再点击文献列表工具栏的书本图标 **阅读管理**。

面板读取当前文献列表，按文献显示卡片；同一文献的多个附件会合并到所属文献。切换分类或搜索后，点击“刷新列表”更新面板内容。

### 已读与未读

- 点击卡片右上角的“未读”即可标记为已读，再次点击“已读”可撤回。
- 顶部“全部／未读／已读”筛选会显示对应数量。
- 当你在“未读”筛选中把一篇标记为已读，这张卡片会从当前结果中移走；到“已读”或“全部”即可找到。
- 顶部进度条表示当前列表中已读文献的比例。

### 每篇文献的生词卡片

点击“生词本 · 数量”展开预览，可看到每个词的释义、熟练度、可用例句和页码。“定位原词”返回 PDF；没有来源时显示“无原文位置”。词多时可以滚动查看，再次点击入口即可收起。

### 阅读笔记

1. 点击“写笔记”，输入主要观点、疑问或读后想法。已有笔记会先以文字展示，点击“编辑笔记”再修改。
2. 点击“保存笔记”，或按 **Ctrl+Enter**（macOS 为 **Cmd+Enter**）保存。
3. 点击“取消”会放弃本次未保存的修改。

笔记默认收起，已保存内容可显示一行摘要。切换生词／笔记、筛选、刷新或收起整个面板时，未保存草稿会在当前窗口内保留；**关闭窗口或重启 Zotero 前请保存**。

阅读管理里的笔记是插件本地记录，不是 Zotero 原生笔记。目前不会自动同步到其他电脑。

## 7. 常见问题

| 问题 | 检查方法 |
| --- | --- |
| 装完还是旧名字／旧界面 | 在插件列表确认版本；重启 Zotero。旧占位更新地址的版本需手动安装一次本仓库 XPI |
| 选中文字不弹窗 | 确认启用 PDF 划词弹窗，且 PDF 有可选文字；必要时重新打开阅读器 |
| 当前文献没有词，全部生词却有 | 检查词是否收录在另一篇文献或另一版本；当前文献范围按来源条目匹配 |
| 自动翻译关闭后没有释义 | 升级 v2.6.0；收录时会主动查询。旧空词条使用“补查释义”修复，或手动修改 |
| 翻译失败 | 在设置中测试连接，检查百度凭据、服务状态与网络；失败词可重试，也可关闭自动翻译后先收录 |
| 点击定位只到页码 | 旧数据可能缺少字符位置；精确定位依赖 PDF 文字层和保存的来源 |
| 阅读管理没有跟随分类变化 | 点击“刷新列表”；它读取的是 Zotero 当前文献列表 |
| 标为已读后卡片消失 | 若正在筛选“未读”，卡片会移出当前结果；切换“全部”或“已读”即可看到 |
| 笔记在另一台电脑不见了 | 阅读记录保存在本机，当前不通过 Zotero 库同步 |

若仍无法解决，请 [提交 Issue](https://github.com/RedkieZhang717/vocabu_text/issues)，附上系统、Zotero 版本、插件版本、操作步骤和脱敏截图。不要公开密钥或私人笔记。
